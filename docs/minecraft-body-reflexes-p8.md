# Minecraft 体の反射（P8）の運用メモ（2026-10-19）

共通 FCA の体（`MINEBOT_COMMON_FCA=on`）に、旧 Minebot が持っていた反射と知識を戻す P8 の、スイッチ・既定・巻き戻しの一覧。設計は `Syzygy/notes/cloud-handoff-2026-10-19/design-p8-body-reflexes.md`。API 側の相手は `codex/shannon/reflex-aware-api`。**本番の env 変更と再起動は、そのつどオーナーに確認する。**

## 何が入っているか

| 部品 | 既定 | 中身 | 場所 |
| --- | --- | --- | --- |
| 床（retreat / eat / armor） | on | 火の付いたクリーパーと飛んでくる矢から下がる（350）、空腹・低体力で食べる（200）、空きスロットに防具と盾（150）。2026-10-16 から本番にある | `utils/floorReflexes.ts` |
| 低体力の逃走（flee） | **on** | 体力 6 以下で、到達できる敵（旧 `isThreatEntity` の判定。固定の名前表ではない）が 8m 内（弓を撃つ種類は 16m）にいれば走り始め、**全部の敵からの斥力の向き**へ、敵が 12m（弓は 20m）より遠くなるまで 1.2 秒ごとの区切りで走り続ける（最大 32 ブロック・6 秒、止まったら 2 秒休み、新しい逃走は 20 秒に 2 回まで）。崖・溶岩・火・クモの巣・壁（半ブロックの床・階段・ハーフブロックの段差は壁にしない）・深い水に向かう向きは取らず、安全な向きが無ければ始めず、台帳に「走れなかった」と残す。詳細は下の「逃走」 | `floorReflexes.ts` |

## スイッチ

`MINEBOT_FCA_REFLEXES`（モード）と `MINEBOT_FCA_REFLEX_OFF`（個別に外す。区切りはカンマ・空白・セミコロンのどれでもよい）。起動時に 1 回だけ読む（`utils/floorConfig.ts`、読み込みは `utils/floorLayer.ts` の 1 か所）。

| `MINEBOT_FCA_REFLEXES` | 意味 |
| --- | --- |
| 未設定 / `default` | 上の表の既定すべて |
| `floor` | **2026-10-16 の本番の床（65b4bd1）そのもの**。retreat / eat / armor だけ。flee・pickup・戦闘知識・**予算は無く**、失敗した食事・防具は元どおり 3 秒固定で再試行し、「敵が近い」は元の 19 種の名前表で判定する。足されているのは動きを変えない報告だけ（台帳・受信票の印・観測の追加項目。印は `ledger-tag` で外せる） |
| `off` | 床を読み込まない。常駐の溶岩・呼吸・盾・踏ん張り・崖際の反射は残る。**本番の床まで止まる**ので、P8 の巻き戻しにはこれを使わない（下の表） |
| `extended` | `default` の旧名（以前は flee と pickup を足すモードだった）。受け付けるが警告を出す |
| それ以外（打ち間違い） | **`floor`（本番の床）** として扱い、起動ログに `‼` 付きのエラー行を出す。P8 全部が誤って入ることも、床が止まる（`off`）こともない |

| `MINEBOT_FCA_REFLEX_OFF` の名前 | 外れるもの |
| --- | --- |
| `retreat` / `eat` / `armor` | 床のそれぞれ |
| `flee` | 低体力の逃走 |
| `pickup` | 拾い物 |
| `combat` | 戦闘知識の部品すべて（盾の学習、掘りの脅威半径、`hitsLeft`、`noteAttackedBy`） |
| `budget` | 床の予算（反射は無制限に戻る。失敗の再試行は 3 秒固定の旧挙動）。`floor` モードには初めから無い |
| `ledger-tag` | 受信票の反射メモと `interrupted_by_reflex`（旧来の `interrupted` に戻る） |

存在しない名前は無視するが、**`‼` 付きのエラー行で名前を挙げて知らせる**（外したつもりのものは外れていない）。そのモードが動かしていないものを外しても何も変わらない。

起動ログの 1 行で、いま何が動いているか分かる:

```
🧱 床の反射: default（retreat,eat,armor,flee,pickup） 台帳=on タグ=on 戦闘知識=on 予算=on 拒否=[]
```

### 部品ごとの巻き戻し

| 戻したいもの | 設定 | 戻り方 |
| --- | --- | --- |
| 低体力の逃走だけ | `MINEBOT_FCA_REFLEX_OFF=flee` | API の fast judgment（flee-from・避難所）だけになる |
| 拾い物だけ | `MINEBOT_FCA_REFLEX_OFF=pickup` | 命令の合間は立っているだけ |
| 戦闘知識 | `MINEBOT_FCA_REFLEX_OFF=combat` | 盾は撃つ種類を学ばない、掘りの敵の半径は既定 16、`hitsLeft` は出ない、被弾した Mob を敵にしない |
| 床の予算 | `MINEBOT_FCA_REFLEX_OFF=budget` | 反射が無制限に戻る |
| 受信票の印 | `MINEBOT_FCA_REFLEX_OFF=ledger-tag` | API は `interrupted` を受け取る（`retry_same`） |
| P8 の運動と知識を全部（2026-10-16 の本番と同じ床） | `MINEBOT_FCA_REFLEXES=floor`（印も戻すなら `MINEBOT_FCA_REFLEX_OFF=ledger-tag`） | 本番の床と同じ |
| 床そのもの | `MINEBOT_FCA_REFLEXES=off` | **本番の床も止まる**。P8 の巻き戻しではなく、床の障害調査用 |
| コード | `git revert`（新しい部品は別ファイル） | |

env を戻して `shannon.service` を再起動する。`MINEBOT_FCA_REFLEXES=off` を誤って入れたかどうかは起動ログの `床の反射: off（なし）` で分かる。

### 外せないもの

台帳の記録、観測の `reflexes`・`biome`、受信票を作る経路は外せない。どれも「起きたことを言う」だけで、体を動かさない。`jobs` は共通 FCA の体（台帳がある体）にだけ出し、旧モードの観測は従来のまま（旧モードには `get-background-jobs` がある）。`biome` は世界から直接読み、読めなければ旧来の `environmentState.biome` に戻すので、旧モードでも値は同じ名前になる。

## 戦闘知識を戻した時に旧と合わせたところ

- **掘りの脅威半径**は固定値ではなく、旧 `EventReactionSystem.emergencyClearanceRadius` の規則どおり（`utils/threatRadius.ts`）。基準は `min(検知 16, 危険距離 8 × 2) = 16`。測定で遠くから当ててくると分かった種類（反射が答える種類と戦闘中の種類は除く）が、届く距離 + 6 以内にいれば「届く距離 + 6」。9 秒以内に着く敵が基準の外にいればその距離 + 4。直近 5 秒の被弾は「当たった距離 + 6」。最大 64。定数は旧のソースと突き合わせるテストがある。
- **`noteAttackedBy`**: サーバーが被弾の原因として名指しした Mob（プレイヤー・飛び道具・物体を除く）を、リストに無くても 5 分間「敵」として扱う。オオカミ・ハチ・ゴーレム・ピグリンが当ててきた場合もそうなり、`nearbyThreats`・掘りの敵判定・ゴール判定に入る。**旧システムも `entityHurt` で同じ呼び出しをしていた**ので、これは旧と同じ挙動の復元（近似ではない）。記憶はモジュール全体で共有される。外すなら `combat`。

## 床の予算（`utils/floorBudget.ts`）

床の反射が動いている間（`facts.floorActive`）は API の fast judgment が黙るので、床が実行権を取り続けると心が進めない。矢が連続する、食べるのが失敗し続ける、で起きうる。

| 規則 | 値 |
| --- | --- |
| 矢のよけの間隔 | 終わってから 2 秒（体力 6 以下は 1 秒） |
| 食事・防具の失敗の待ち | 3 秒、6 秒、12 秒…最大 30 秒。途中で切られただけなら 3 秒。**体力 6 以下か満腹度 6 以下（飢え）の食事は別**: 割り当ても止め（latch）も無く、失敗しても 3 秒待つだけで何度でも試す（旧 auto-eat は 1 秒ごとに無制限に試していて、API の fast judgment は食べないため、食べるのを止めると詰む）。その時間は割り当てに数えない |
| 割り当て | 矢のよけ・食事・防具の合計で 60 秒に 15 秒まで（体力 6 以下は対象外） |
| 止め（latch） | 同じ反射が 3 回続けて失敗したら 60 秒止める（次は 120 秒、最大 240 秒）。成功で消える |
| 対象外 | 火の付いたクリーパーからの退避、低体力の逃走（自前で 20 秒に 2 回）、溶岩・呼吸（床ではない）、体力 6 以下・飢えの食事（上） |

止まった時は黙らず、台帳に `budget` の 1 行（`state.world.reflexes` に出る）を残し、`facts.floorSilenced`（`arrow` / `eat` / `armor` / `budget` のカンマ区切り、無ければ null）で保持中を示す。ログは `🚦`。

## 逃走（低体力の flee）の数字

`utils/floorReflexes.ts`。旧 Minebot（e94a236）の自動逃走（autoRunFromHostiles と EventReactionSystem の継続逃走）と、2026-10-16 の本番（逃走が無い）に対する位置づけは次のとおり。

| | 旧 Minebot | 本番 65b4bd1 | 今回（default） |
| --- | --- | --- | --- |
| 敵の判定 | `isThreatEntity`（ピグリンは金の防具が無い時、ゾンビピグリンとエンダーマンは怒った時か被弾後、被弾した種類は 5 分、ゲームの hostile 分類） | 逃走なし | **同じ `isThreatEntity`**（食事・防具・拾い物の「敵が近い」も同じ。`floor` モードだけ元の名前表） |
| 始める体力 | 5 以下 | － | 6 以下（API の `lowHealth`） |
| 始める距離 | 16m（壁越しでも） | － | 8m、弓を撃つ種類は 16m。壁に囲まれて届かない敵は数えない（旧が洞窟の別室の敵から逃げようとして動けなかった L33 を避ける） |
| 走る向き | autoRun は経路探索で平均位置から離れる。継続逃走は全敵の「隙間」の向き（斥力の合算は打ち消し合う） | － | **全敵の斥力（近いほど重い）**。打ち消し合う時と、押された先が別の敵に近づく時は旧の隙間の向き（`escapeHeading`）。そのまわりの安全な向き（±45°、±90°）を探し、別の敵に近づく向きは取らない |
| 走る長さ | 約 32m（敵の平均位置から 32m 離れるまで、1 秒ごとに繰り返す） | － | 1.2 秒・7 ブロックごとの区切りを、敵が 12m（弓 20m）より遠くなるまで、または出発点から 32 ブロック・6 秒まで続ける。進まない区切りが 2 回続けば止める |
| 実行中の行動 | 動いている skill があれば走らない（その間は緊急対応の層が見ていた） | － | 戦闘・作業を切る（今の作りに緊急対応の層が無く、API の fast judgment も同じ体力で切るため）。API 自身の逃げ・避難所（`flee-from` / `dig-shelter` / `build-around-self`）は切らない。API の命令がこの区切りを待っていたら 0.2 秒後に区切りを終えて渡し、2 秒は取り返さない |
| 歯止め | なし（敵が居る限り走り続ける） | － | 逃走の開始は 20 秒に 2 回まで、止まったあと 2 秒の休み、1 区切りは 1.2 秒（API の release が待つ 3 秒に収まる） |
| 足元 | 崖だけ見て、見つからなければ元の向きで走る | － | 溶岩・火・クモの巣・サボテン・スイートベリー・粉雪・マグマ・焚き火、3 ブロック超の落差、壁・天井、水の中では岸に届かない向き、陸からは深い水、のどれかなら取らない。**取れる向きが無ければ走らず**、台帳に残して API の判断に任せる（0.5 秒は地面を読み直さない） |
| 半ブロックの床 | － | － | 足元は「足が載っているブロック」（`floor(y - 0.01)`）で読む。ハーフ・階段・ソウルサンド・耕地・土の道・カーペット・泥・ハチミツ・スイレンの上でも始まる（3 回目の H1） |

食事（旧 auto-eat / 本番の床 / 今回）: 旧は満腹度 18 未満か、体力 18 未満で満腹度 20 未満で、動いていなければいつでも食べ、敵の有無は見ず、1 秒ごとに無制限に試した。本番の床は満腹度 6 以下か、体力 12 以下で満腹度 18 未満の時だけ、敵が 5m 内なら食べない（敵に囲まれて立ち止まって食べて死んだ L18）、毒になる食べ物は避ける。今回は、その条件は本番と同じまま、**体力 6 以下か満腹度 6 以下では予算の対象外**（latch・割り当てなし、3 秒の待ちだけ）にして、旧の「無制限に試す」を戻した。「敵が 5m 内」は旧 `isThreatEntity` の判定。食べる閾値（満腹度 6 以下／体力 12 以下で満腹度 18 未満）は本番のままで、旧のように満腹度 18 未満で常に食べるわけではない（体力が満タンで満腹度が 7〜17 の時は計画器が決める）。

## ラボ用プローブの床

`testing/MinecraftProbeBot.ts` は、床を自分で言う（クライアントの設定を受け継がない）。既定は `MINECRAFT_PROBE_FLOOR` 未設定 = **2026-10-16 の本番の床だけ**（retreat / eat / armor。flee・予算・拾い物は無い。これまでのプローブの結果はその床で取ったため）。`MINECRAFT_PROBE_FLOOR=default` で、クライアントと同じに `MINEBOT_FCA_REFLEXES` / `MINEBOT_FCA_REFLEX_OFF` を読んだ床（flee と予算を含む。拾い物と戦闘知識はクライアントの層なので載らない）、`off` で床なし。
## API 側（`codex/shannon/reflex-aware-api`）

- `interrupted_by_reflex` は `retry_same`。失敗の数に数えない。ただし同じ道具が 3 回続けて（道具が混ざれば 6 回続けて）切られたら普通の失敗として数え、5 で止める。**読み取りだけの成功（`minecraft.observe` や問い合わせ）は、この連続を断ち切らない**。止める時の理由は、**切られた分が失敗の数を限度に押し上げた時だけ** `repeated_reflex_interruption`（その時に限度に届いたのが普通の失敗なら、切られた連続が続いていても `repeated_tool_failure`）。
- fast judgment は、反射に切られた避難所を「隠れ失敗」と数えない。
