# Minecraft 体の反射（P8）の運用メモ（2026-10-19）

共通 FCA の体（`MINEBOT_COMMON_FCA=on`）に、旧 Minebot が持っていた反射と知識を戻す P8 の、スイッチ・既定・巻き戻しの一覧。設計は `Syzygy/notes/cloud-handoff-2026-10-19/design-p8-body-reflexes.md`。API 側の相手は `codex/shannon/reflex-aware-api`。**本番の env 変更と再起動は、そのつどオーナーに確認する。**

> 2026-10-24: 体の LLM 中心の作り（旧 `MINEBOT_LLM_CENTRIC=on`）が唯一の作りになった。切り替えは無い。床は自分で防具を着けず（`armor` の反射は無い）、手が空いても拾い物に歩かず（`pickup` は無い）、食べるのは飢え（満腹度 3 以下）か瀕死（体力 6 以下）の時だけ。逃げ道が無い時は囲わずに最後の一手（殴る・1 段下りる・1 段上がる）をする。下の表のうち防具・拾い物・つまみ食いの記述は過去の記録。

## スイッチ

`MINEBOT_FCA_REFLEXES`（モード）と `MINEBOT_FCA_REFLEX_OFF`（個別に外す。区切りはカンマ・空白・セミコロンのどれでもよい）。起動時に 1 回だけ読む（`utils/floorConfig.ts`、読み込みは `utils/floorLayer.ts` の 1 か所）。

| `MINEBOT_FCA_REFLEXES` | 意味 |
| --- | --- |
| 未設定 / `default` | 上の表の既定すべて |
| `floor` | **2026-10-16 の本番の床（65b4bd1）そのもの**。retreat / eat / armor だけ。flee・pickup・戦闘知識・**予算は無く**、失敗した食事・防具は元どおり 3 秒固定で再試行し、「敵が近い」は元の 19 種の名前表で判定する。足されているのは動きを変えない報告だけ（台帳・受信票の印・観測の追加項目。印は `ledger-tag` で外せる） |
| `off` | 床を読み込まない。常駐の溶岩・呼吸・盾・踏ん張り・崖際の反射は残る。**本番の床まで止まる**ので、P8 の巻き戻しにはこれを使わない（下の表） |
| `extended` | `default` の旧名（以前は flee と pickup を足すモードだった）。受け付けるが警告を出す |
| それ以外（打ち間違い） | **`floor`（本番の床）** として扱い、起動ログに `‼` 付きのエラー行を出す。P8 全部が誤って入ることも、床が止まる（`off`）こともない |

| `MINEBOT_FCA_REFLEX_OFF` の名前 | 外れるもの |
| --- | --- |
| `retreat` / `eat` | 床のそれぞれ |
| `flee` | 低体力の逃走 |
| `combat` | 戦闘知識の部品すべて（盾の学習、掘りの脅威半径、`hitsLeft`、`noteAttackedBy`） |
| `budget` | 床の予算（反射は無制限に戻る。失敗の再試行は 3 秒固定の旧挙動）。`floor` モードには初めから無い |
| `ledger-tag` | 受信票の反射メモと `interrupted_by_reflex`（旧来の `interrupted` に戻る） |

存在しない名前は無視するが、**`‼` 付きのエラー行で名前を挙げて知らせる**（外したつもりのものは外れていない）。そのモードが動かしていないものを外しても何も変わらない。

起動ログの 1 行で、いま何が動いているか分かる:

```
🧱 床の反射: default（retreat,eat,flee） 台帳=on タグ=on 戦闘知識=on 予算=on 拒否=[]
```

### 部品ごとの巻き戻し

| 戻したいもの | 設定 | 戻り方 |
| --- | --- | --- |
| 低体力の逃走だけ | `MINEBOT_FCA_REFLEX_OFF=flee` | API の fast judgment（flee-from・避難所）だけになる |
| 戦闘知識 | `MINEBOT_FCA_REFLEX_OFF=combat` | 盾は撃つ種類を学ばない、掘りの敵の半径は既定 16、`hitsLeft` は出ない、被弾した Mob を敵にしない |
| 床の予算 | `MINEBOT_FCA_REFLEX_OFF=budget` | 反射が無制限に戻る |
| 受信票の印 | `MINEBOT_FCA_REFLEX_OFF=ledger-tag` | API は `interrupted` を受け取る（`retry_same`） |
| P8 の運動と知識を全部（2026-10-16 の本番と同じ床） | `MINEBOT_FCA_REFLEXES=floor`（印も戻すなら `MINEBOT_FCA_REFLEX_OFF=ledger-tag`） | 本番の床と同じ |
| 床そのもの | `MINEBOT_FCA_REFLEXES=off` | **本番の床も止まる**。P8 の巻き戻しではなく、床の障害調査用 |
| コード | `git revert`（新しい部品は別ファイル） | |

env を戻して `shannon.service` を再起動する。`MINEBOT_FCA_REFLEXES=off` を誤って入れたかどうかは起動ログの `床の反射: off（なし）` で分かる。

### 外せないもの

台帳の記録、観測の `reflexes`・`biome`、受信票を作る経路は外せない。どれも「起きたことを言う」だけで、体を動かさない。`jobs` は共通 FCA の体（台帳がある体）にだけ出し、旧モードの観測は従来のまま（旧モードには `get-background-jobs` がある）。`biome` は世界から直接読み、読めなければ旧来の `environmentState.biome` に戻すので、旧モードでも値は同じ名前になる。

## 戦闘知識を戻した時に旧と合わせたところ

- **掘りの脅威半径**は固定値ではなく、旧 `EventReactionSystem.emergencyClearanceRadius` の規則どおり（`utils/threatRadius.ts`）。基準は `min(検知 16, 危険距離 8 × 2) = 16`。測定で遠くから当ててくると分かった種類（反射が答える種類と戦闘中の種類は除く）が、届く距離 + 6 以内にいれば「届く距離 + 6」。9 秒以内に着く敵が基準の外にいればその距離 + 4。直近 5 秒の被弾は「当たった距離 + 6」。最大 64。定数は旧のソースと突き合わせるテストがある。
- **`noteAttackedBy`**: サーバーが被弾の原因として名指しした Mob（プレイヤー・飛び道具・物体を除く）を、リストに無くても 5 分間「敵」として扱う。オオカミ・ハチ・ゴーレム・ピグリンが当ててきた場合もそうなり、`nearbyThreats`・掘りの敵判定・ゴール判定に入る。**旧システムも `entityHurt` で同じ呼び出しをしていた**ので、これは旧と同じ挙動の復元（近似ではない）。記憶はモジュール全体で共有される。外すなら `combat`。

## 床の予算（`utils/floorBudget.ts`）

床の反射が動いている間（`facts.floorActive`）は API の fast judgment が黙るので、床が実行権を取り続けると心が進めない。矢が連続する、食べるのが失敗し続ける、で起きうる。

| 規則 | 値 |
| --- | --- |
| 矢のよけの間隔 | 終わってから 2 秒（体力 6 以下は 1 秒） |
| 食事・防具の失敗の待ち | 3 秒、6 秒、12 秒…最大 30 秒。途中で切られただけなら 3 秒。**止められない食事（満腹度 6 以下、または 体力 6 以下で満腹度 17 以下。体力 6 以下でも満腹度 18〜19 は得るものが無いので通常の補給として割り当てに数える。床の選択・tick・割り当ての 3 か所で同じ定義 `eatIsCritical`）は別**: 割り当ても止め（latch）も無く、失敗しても 3 秒待つだけで何度でも試す（旧 auto-eat は 1 秒ごとに無制限に試していて、API の fast judgment は食べないため、食べるのを止めると詰む）。その時間は割り当てに数えない |
| 割り当て | 矢のよけ・食事・防具の合計で 60 秒に 15 秒まで（体力 6 以下は対象外） |
| 止め（latch） | 同じ反射が 3 回続けて失敗したら 60 秒止める（次は 120 秒、最大 240 秒）。成功で消える |
| 対象外 | 火の付いたクリーパーからの退避、低体力の逃走（自前で 20 秒に 2 回）、溶岩・呼吸（床ではない）、体力 6 以下・飢えの食事（上） |

止まった時は黙らず、台帳に `budget` の 1 行（`state.world.reflexes` に出る）を残し、`facts.floorSilenced`（`arrow` / `eat` / `armor` / `budget` のカンマ区切り、無ければ null）で保持中を示す。ログは `🚦`。

## 逃走（低体力の flee）の数字

`utils/floorReflexes.ts`。旧 Minebot（e94a236）の自動逃走（autoRunFromHostiles と EventReactionSystem の継続逃走）と、2026-10-16 の本番（逃走が無い）に対する位置づけは次のとおり。

| | 旧 Minebot | 本番 65b4bd1 | 今回（default） |
| --- | --- | --- | --- |
| 敵の判定 | `isThreatEntity`（ピグリンは金の防具が無い時、ゾンビピグリンとエンダーマンは怒った時か被弾後、被弾した種類は 5 分、ゲームの hostile 分類） | 逃走なし | **同じ `isThreatEntity`**（食事・防具・拾い物の「敵が近い」も同じ。`floor` モードだけ元の名前表） |
| 始める体力 | 5 以下 | － | 6 以下（API の `lowHealth`） |
| 始める距離 | 16m（壁越しでも） | － | 8m、弓を撃つ種類は 16m。壁に囲まれて届かない敵は数えない（旧が洞窟の別室の敵から逃げようとして動けなかった L33 を避ける） |
| 走る向き | autoRun は経路探索で平均位置から離れる。継続逃走は全敵の「隙間」の向き（斥力の合算は打ち消し合う） | － | **全敵の斥力（近いほど重い）**。打ち消し合う時と、押された先が別の敵に近づく時は旧の隙間の向き（`escapeHeading`）。そのまわりの安全な向き（±45°、±90°）を探し、別の敵に近づく向きは取らない |
| 走る長さ | 約 32m（敵の平均位置から 32m 離れるまで、1 秒ごとに繰り返す） | － | 1.2 秒・7 ブロックごとの区切りを、敵が 12m（弓 20m）より遠くなるまで、または出発点から 32 ブロック・6 秒まで続ける。進まない区切りが 2 回続けば止める |
| 実行中の行動 | 動いている skill があれば走らない（その間は緊急対応の層が見ていた） | － | 戦闘・作業を切る（今の作りに緊急対応の層が無く、API の fast judgment も同じ体力で切るため）。API 自身の逃げ・避難所と、体を危険から出す命令（`flee-from` / `dig-shelter` / `build-around-self` / `leave-water` / `tower-up` / `climb-down` / `enter-portal`。API の DEFENSIVE_SKILLS のうち戦闘の `attack-*` / `retreat-attack` は API の fast judgment も体力 6 以下で切るので含めない）は、`default` の床の反射のどれも切らない（逃走は始めず、食事と防具の着用は待ち、矢のよけは出さない）。**唯一の例外は満腹度 3 以下の食事**（本当の飢え）で、もう一つ、火の付いたクリーパーからの退避は爆発の 1 秒前なので本番どおり切る（`floor` モードは本番のまま、どれも切る）。API の命令がこの区切りを待っていたら 0.2 秒後に区切りを終えて渡し、2 秒は取り返さない |
| 歯止め | なし（敵が居る限り走り続ける） | － | 逃走の開始は 20 秒に 2 回まで、止まったあと 2 秒の休み、1 区切りは 1.2 秒（API の release が待つ 3 秒に収まる） |
| 足元 | 崖だけ見て、見つからなければ元の向きで走る | － | 溶岩・火・クモの巣・サボテン・スイートベリー・粉雪・マグマ・焚き火・ポータル（ネザー・エンド・ゲートウェイ）・感圧板・トリップワイヤー（罠）、3 ブロック超の落差（石筍＝尖った鍾乳石の上への落下も）、壁・天井、水の中では岸に届かない向き、陸からは深い水、のどれかなら取らない。**線が通るマスを全部**（0.25 ブロックごとに読み、斜めでも飛ばさない）、**体の幅（線の両側 0.4 ブロック）が触れるマスの罠も**見る。1 ブロック登る先の足場（跳び乗るブロックそのもの。マグマ・焚き火・サボテンなどは断る）と、跳んだあと頭が届くマス（溶岩・火・クモの巣などは断る）も見る。**取れる向きが無ければ走らず**、台帳に残して API の判断に任せる（0.5 秒は地面を読み直さない） |
| 段差と坂 | pathfinder（ジャンプで 1 段上がり、坂を下る） | － | 向きを 1 ブロックずつ**体の高さを追って**読む（5 ブロック先まで）。1 ブロックの段（丸ごとの 1 ブロック）は、その上に体が入る 2 マス、と踏み切る側の頭上 1 マス（pathfinder の跳ぶ条件と同じ）が空いていればジャンプで上がり、走る側が sprint ジャンプを押す（1〜2 マス先の段でだけ）。1 ブロックごとの登り坂・下り坂はそのまま走る。落差は「その手前 2 ブロック（直線なら 2 マス）の床のうち一番高いところから」見て 3 ブロックを超えるマスを断る。坂全体の合計では断らない: 1 ブロックごと（1:1）・1.5 ブロックごと（1.5:1）の下り坂は走るが、2 ブロックごと（2:1）以上の階段状の下りは断る（走る体は 1 段で止まらず次の段を越えて飛ぶため。実物理で 2:1 は 6 ブロック、3:1 は 15 ブロック落ちた）。ジャンプが要る向きは、その跳躍の頂点（踏み切りの 1.25 ブロック上）からの落差で全マスを見る（飛ぶ体は着地点を選べない）。ジャンプは体の速度が向きに沿っている時（または止まっている時）に押し、空中では向きを変えず、水の中ではジャンプ（上へ泳ぐ）で岸に上がる（水面と同じ高さの岸だけ。水面より高い岸は壁）。階段は向きが当たる側で見る（前の低い段は歩いて上がる、背中側は 1 ブロックの段でジャンプ）。頭上が 2 マスしか空いていない斜めの坑道は上がれない（pathfinder と同じ） |
| 複数の敵 | － | － | 前の区切りの向きが、まだ安全で、敵に近づかず、新しい斥力の向きから 45° 以内なら、その向きを保つ（敵が動くたびの蛇行を防ぐ。敵が 1 体の時は保たない） |
| 半ブロックの床 | － | － | 足元は「足が載っているブロック」（`floor(y - 0.01)`）で読む。ハーフ・階段・ソウルサンド・耕地・土の道・カーペット・泥・ハチミツ・スイレンの上でも始まる（3 回目の H1） |

食事（旧 auto-eat / 本番の床 / `default` / `floor`）。**`default` の食べる条件は旧に戻した**（2026-10-19、オーナー基準「前より良い」）。`floor` は本番 65b4bd1 のまま変えていない:

| | 旧 auto-eat（e94a236） | 本番の床 / `floor` モード | **`default`（新）** |
|---|---|---|---|
| 食べ始める条件 | 満腹度 18 未満、または 体力 18 未満で満腹度 20 未満 | 満腹度 6 以下、または 体力 12 以下で満腹度 18 未満 | **旧と同じ**（満腹度 17 以下、または 体力 17 以下で満腹度 19 以下） |
| 歩いている間（pathfinder） | 体力 8 以下か満腹度 6 以下の時だけ | 見ない | **旧と同じ**（体力 8 以下か満腹度 6 以下の時だけ） |
| 敵が 5m 内 | 見ない（食べる） | 食べない（L18。瀕死でも食べない） | **食べない**（本番どおり。瀕死でも。旧より安全な方を取った。敵は `isThreatEntity`） |
| 毒になる食べ物 | 区別なし（何でも） | 避ける（フグ・チョルスの実・不審なシチュー・クモの目・毒ジャガイモ・エンチャント金リンゴは食べない。腐った肉は満腹度 6 以下の時だけ） | 本番と同じ |
| 実行中の API 命令・待っている命令 | 見ない（旧には API の実行権が無く、実行中の skill を `shouldPreempt` で止めて食べた: 体力 8 以下か満腹度 6 以下） | 満腹度 3 以下か体力 6 以下でだけ命令を切る。それ以外は手が空くまで待つ | **補給（危機でない食事）は体を使う命令が走っていない・待っていない時だけ、かつ制御ループが命令・所有・保持をしていない時（`fcaLeaseHeld`: モデルが考えている間に次の命令を遅らせない）だけ**。危機 = 満腹度 6 以下、または 体力 6 以下で満腹度 17 以下（体力 6 以下でも満腹度 18〜19 は得るものが無いので補給）。危機は止められず、命令を切るのは本番と同じく満腹度 3 以下か体力 6 以下。**ただし API 自身の逃げ・避難所と、体を危険から出す命令（`flee-from` / `dig-shelter` / `build-around-self` / `leave-water` / `tower-up` / `climb-down` / `enter-portal`）は満腹度 3 以下（本当の飢え）でしか切らない**（唯一の例外） |
| 食べる物の選び方 | 満腹度の回復量が多い順に何でも | 同じ（毒になる物は除く） | 同じ。**ただし補給は貴重な食べ物（金のリンゴ・金のニンジン・ハチミツ入りの瓶）を食べない**（普通の食べ物があればそれを食べ、貴重な物しか無ければ補給は食べない）。危機は貴重な物も食べる |
| 「敵が 5m 内」 | 見ない | 敵の名前表（壁越しも数える） | `isThreatEntity` で、**壁越しで届かない敵（`threatExposure` が sealed）は数えない**（逃走と同じ判定）。`floor` は元のまま |
| 予算 | 無制限（1 秒ごと） | `floor` は予算なし（失敗は 3 秒固定） | 危機は予算の対象外（latch・割り当てなし、失敗しても 3 秒待つだけ）。補給は従来の予算（失敗の待ちと latch、60 秒に 15 秒の割り当て）に従う |

旧との差と理由: ① 旧は体力 8 以下か満腹度 6 以下なら実行中の skill を止めて食べたが、`default` は体力 7〜8（満腹度 7 以上）では命令を切らない。API の命令を切る害の方が大きく（旧には API の実行権が無かった）、補給は手が空いた時にやれば栄養は同じだけ入る。体力 6 以下か満腹度 3 以下の時は切る。② 旧は敵の目の前でも食べたが、本番と同じく食べない（立ち止まって食べて死んだ L18）。体力 6 以下で敵が近くても、逃走が先に走る**とは限らない**: 逃走は、休み中（止まったあと 2 秒）、20 秒に 2 回の割り当てを使い切った時、安全な逃げ道が無い時（台帳に「走れなかった」）、API の逃げ・避難所（`flee-from` / `dig-shelter` / `build-around-self`）が走っている時、別の床の反射（退避・食事・防具）や溶岩・呼吸の反射が体を持っている時は始まらない。その時は API の fast judgment が決める（逃げ・避難所・戦闘）。敵が 5m 内の間は食事も始まらない（壁越しの敵は数えない）。③ 旧は毒になる食べ物も食べたが避ける。④ 実行中の命令が無くても pathfinder が歩いている間は、旧と同じく体力 8 以下か満腹度 6 以下の時だけ食べる。実装は `floorEatChoice(bot, wide)`（`wide` = `default`）。

## ラボ用プローブの床

`testing/MinecraftProbeBot.ts` は、床を自分で言う（クライアントの設定を受け継がない）。既定は `MINECRAFT_PROBE_FLOOR` 未設定 = **2026-10-16 の本番の床だけ**（retreat / eat / armor。flee・予算・拾い物は無い。これまでのプローブの結果はその床で取ったため）。`MINECRAFT_PROBE_FLOOR=default` で、クライアントと同じに `MINEBOT_FCA_REFLEXES` / `MINEBOT_FCA_REFLEX_OFF` を読んだ床（flee と予算を含む。拾い物と戦闘知識はクライアントの層なので載らない）、`off` で床なし。

## API 側（`codex/shannon/reflex-aware-api`）

- `interrupted_by_reflex` は `retry_same`。失敗の数に数えない。ただし同じ道具が 3 回続けて（道具が混ざれば 6 回続けて）切られたら普通の失敗として数え、5 で止める。**読み取りだけの成功（`minecraft.observe` や問い合わせ）は、この連続を断ち切らない**。止める時の理由は、**切られた分が失敗の数を限度に押し上げた時だけ** `repeated_reflex_interruption`（その時に限度に届いたのが普通の失敗なら、切られた連続が続いていても `repeated_tool_failure`）。
- fast judgment は、反射に切られた避難所を「隠れ失敗」と数えない。

  - 戦闘知識（盾の学習、掘りの脅威半径、`hitsLeft`、被弾した Mob を敵にする）

### 反映後に見るもの（`journalctl -u shannon.service`、API 側の台帳）

1. 体のログインの後、起動の 1 行: `🧱 床の反射: default（retreat,eat,flee） 台帳=on タグ=on 戦闘知識=on 予算=on 拒否=[]`。`‼` 付きの行が出ていたら設定の打ち間違い。

### 分かっている残り（P8 の最終レビュー時点）

- 危険物の多い地形で、安全な向きが残っていない時に、危険物へ滑り込む確率が **約 0.1〜0.3%**。安全な向きが無ければ走らずに断り（台帳に `flee ... failed`）、その時は API に実行権が渡る。
- `ESCAPE_SKILLS`（`flee-from` / `dig-shelter` / `build-around-self` / `leave-water` / `tower-up` / `climb-down` / `enter-portal`）で床の反射が API の逃げを切らない保護は **`default` だけ**で、対象は**トップレベルの命令だけ**。`floor` モードは本番どおり、どれも切る。
- ジャンプの許容 `JUMP_ALONG` = 0.9（`floorReflexes.ts`）。実物理の試験 12,500 例のうち 1 例でこの許容に当たった。
- `prismarine-physics` は推移的なテスト依存（flee の物理試験だけが使う。実行時の import は `vec3` だけ）。

- 逃走の計画（向きの読み取り）は 1 回あたり **平均 0.1 ms 未満、最大 0.4 ms**。
